# astrbot_plugin_anime_birthday

[![Version](https://img.shields.io/badge/version-v1.0.0-blue.svg)](https://github.com/ma114514/astrbot_plugin_anime_birthday/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![AstrBot Plugin](https://img.shields.io/badge/AstrBot-Plugin-4c8bf5)](https://astrbot.app/)

一款适用于 AstrBot 的角色生日提醒插件。它可以查询指定日期过生日的动漫、Galgame 和二次元游戏角色，也可以每天定时向群聊或私聊发送生日提醒。

角色生日与作品信息来自[萌娘百科](https://zh.moegirl.org.cn/)，查询结果会缓存在 AstrBot 的本地数据目录中。

当前版本：**v1.0.0**

## 主要功能

- 查询今天有哪些角色过生日。
- 查询任意日期的角色生日，支持 `2月29日`。
- 按 Galgame、二次元游戏、番剧或全部类型筛选。
- 在指定群聊或私聊中订阅每日推送。
- 自定义每天的推送时间，统一使用北京时间。
- 将查询结果缓存在本地，减少重复访问数据源。
- 网络请求失败时尽量使用已保存的数据。
- 支持 QQ `aiocqhttp` 合并转发消息。

## 安装

### 方法一：使用 AstrBot WebUI

1. 打开 AstrBot WebUI。
2. 进入 **插件** 页面。
3. 点击安装插件，选择通过仓库地址安装。
4. 填入下面的地址：

   ```text
   https://github.com/ma114514/astrbot_plugin_anime_birthday
   ```

5. 等待插件安装并加载完成。

也可以在 [Releases](https://github.com/ma114514/astrbot_plugin_anime_birthday/releases) 页面下载 ZIP，然后在 AstrBot WebUI 中上传安装。

### 方法二：手动安装

进入 AstrBot 的插件目录后执行：

```bash
cd AstrBot/data/plugins
git clone https://github.com/ma114514/astrbot_plugin_anime_birthday.git
cd astrbot_plugin_anime_birthday
```

安装完成后，在 AstrBot WebUI 中重新加载插件。如果依赖没有自动安装，可以执行：

```bash
python -m pip install -r requirements.txt
```

插件需要 Python 3.10 或更高版本，第三方依赖为 `aiohttp`。

## 三步开始使用

### 第一步：测试查询

向机器人发送：

```text
/今日生日
```

如果机器人返回当天的角色列表，说明插件已经可以正常查询数据。

### 第二步：订阅每日推送

在希望收到提醒的群聊或私聊中发送：

```text
/生日订阅 全部
```

订阅只对当前会话生效。如果多个群都要接收提醒，需要分别在每个群中发送订阅命令。

### 第三步：测试主动推送

管理员发送：

```text
/生日测试
```

插件会立即向所有已订阅会话发送一次当天的生日内容。测试推送不会占用当天的自动推送记录。

## 查询命令

查询命令默认所有人都可以使用。

| 命令 | 作用 | 示例 |
| --- | --- | --- |
| `/今日生日` | 查询今天全部类型的生日角色 | `/今日生日` |
| `/今日生日 类型` | 查询今天指定类型的生日角色 | `/今日生日 番剧` |
| `/生日查询 日期` | 查询指定日期的全部角色 | `/生日查询 3月8日` |
| `/生日查询 日期 类型` | 查询指定日期和类型 | `/生日查询 3-8 游戏` |

日期支持以下写法：

```text
3月8日
3-8
3/8
```

## 管理命令

默认只有 AstrBot 管理员可以使用这些命令。将配置项 `admin_only` 关闭后，普通用户也可以执行。

| 命令 | 作用 |
| --- | --- |
| `/生日订阅 gal` | 当前会话只接收 Galgame 角色生日 |
| `/生日订阅 游戏` | 当前会话只接收二次元游戏角色生日 |
| `/生日订阅 番剧` | 当前会话只接收番剧角色生日 |
| `/生日订阅 全部` | 当前会话接收全部角色生日 |
| `/生日退订` | 取消当前会话的每日推送 |
| `/生日订阅列表` | 查看已经订阅的会话和订阅类型 |
| `/生日测试` | 立即向全部订阅会话发送一次测试推送 |
| `/生日缓存` | 查看本地缓存的日期、角色、作品和文件大小 |
| `/生日刷新` | 立即更新今天的数据 |
| `/生日刷新 3月8日` | 立即更新指定日期的数据 |

## 可用类型

| 类型 | 可用写法 | 说明 |
| --- | --- | --- |
| Galgame | `gal`、`galgame`、`美少女游戏` | Galgame 角色 |
| 二次元游戏 | `游戏`、`手游`、`二次元游戏`、`game` | 其他二次元游戏角色 |
| 番剧 | `番剧`、`动画`、`动漫`、`anime` | 动画作品角色 |
| 全部 | `全部`、`都`、`all` | 显示所有类型 |

作品类型由页面信息自动判断，少量角色可能因为资料不完整而分类不准确。

## 配置说明

配置可以在 AstrBot WebUI 的插件配置页面修改。保存配置后建议重新加载插件，确保定时任务使用新设置。

| 配置项 | 默认值 | 新手说明 |
| --- | ---: | --- |
| `send_hour` | `8` | 每天几点推送，范围为 0～23 |
| `send_minute` | `0` | 每天第几分钟推送，范围为 0～59 |
| `max_characters` | `30` | 每个文本分组最多显示多少位角色 |
| `only_with_origin` | `true` | 是否隐藏无法识别出处的角色 |
| `use_forward` | `false` | 是否在 QQ `aiocqhttp` 中使用合并转发 |
| `admin_only` | `true` | 是否只允许管理员执行订阅和刷新等管理命令 |
| `birthday_cache_days` | `30` | 生日数据保存多少天后需要重新获取 |
| `work_cache_days` | `180` | 作品类型保存多少天后需要重新判断 |
| `memory_cache_days` | `8` | 内存中最多保留多少个日期的数据 |
| `request_interval_ms` | `500` | 两次网络请求之间至少间隔多少毫秒 |
| `request_timeout` | `20` | 单次网络请求最多等待多少秒 |
| `max_forward_characters` | `100` | 合并转发最多显示多少位角色 |

例如，要设置每天晚上 8 点 30 分推送，请在插件配置页面将 `send_hour` 填为 `20`，将 `send_minute` 填为 `30`，保存后重新加载插件。

时间始终按北京时间计算，不受服务器时区影响。

## 每日推送说明

- 到达设定时间后，插件会向每个已订阅会话发送当天的生日内容。
- AstrBot 启动时如果已经过了发送时间，会为当天尚未成功发送的会话补发。
- 单个会话发送失败不会影响其他会话。
- 失败的会话会等待约 10 分钟后重试，当天最多尝试 3 次。
- 机器人必须拥有在目标群聊或私聊中主动发送消息的权限。
- 如果平台不支持主动消息，订阅可以保存，但定时推送可能无法送达。

## 本地缓存

插件将数据保存到 AstrBot 分配的插件数据目录中，主要文件为：

```text
data/plugin_data/astrbot_plugin_anime_birthday/
└── birthdays.sqlite3
```

数据库中保存生日数据、作品分类、订阅会话和最近发送日期。更新或重新安装插件时，请保留这个数据目录，订阅和缓存才能继续使用。

插件只在查询或推送某个日期时获取该日期的数据，不需要预先下载全年内容。缓存到期后会按需更新；更新失败且本地已有数据时，会继续使用本地内容并在消息中提示。

## 常见问题

### 机器人没有回复查询命令

1. 在 AstrBot WebUI 中确认插件已经启用。
2. 查看 AstrBot 日志中是否有插件加载错误。
3. 确认 AstrBot 所在设备能够访问 `https://zh.moegirl.org.cn/`。
4. 检查 `aiohttp` 是否已经正确安装。

### 查询提示数据源暂时不可用

数据源可能正在限流、维护，或者当前网络无法访问。等待一段时间后重试；如果本地已经有缓存，插件会尽量返回已保存的数据。

### 到时间没有自动推送

1. 发送 `/生日订阅列表`，确认当前会话已经订阅。
2. 检查 `send_hour` 和 `send_minute`，时间使用北京时间。
3. 发送 `/生日测试`，确认机器人可以向订阅会话主动发消息。
4. 查看 AstrBot 日志中的推送错误。

### 返回的角色太少

默认会隐藏没有出处的角色。可以在配置中关闭 `only_with_origin`，然后重新查询。

### 如何取消推送

在需要取消提醒的群聊或私聊中发送：

```text
/生日退订
```
